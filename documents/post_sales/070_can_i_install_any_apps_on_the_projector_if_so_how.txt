FAQ: Can I install any apps on the projector? If so, How?
──────────────────────────────────────────────────
1. Go to Home > APPs > search bar where you can install the desired app.
Or you can:
2. Download the app's APK file from the Internet and then store it on a USB flash drive.
3. Download a file browser or file management app (e.g. File Manager) onto a USB flash drive, then connect the flash drive to the projector
4. The projector will be able to read the file on the flash drive and install it.
NOTE:
Please note that BenQ is not responsible for third-party app installations using APKs.
